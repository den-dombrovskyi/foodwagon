# 🍔 FoodWagon — Landing Page

Інтерактивний лендінг сервісу доставки їжі, зверстаний за макетом із Figma.

## 🚀 Живе демо (Live Demo)

👉 [Переглянути сайт на GitHub Pages](https://den-dombrovskyi.github.io/foodwagon/)

## 🛠 Використані технології та інструменти

- **HTML5** — семантична верстка.
- **CSS3** — Flexbox, кастомні стилі, оптимізація під стандарти макету.
- **JavaScript (ES6+)** — інтерактивна форма передплати, динамічна обробка кліків та генерація пошуку через Google URL.
- **Figma** — робота з макетом, експорт векторної та растрової графіки (SVG, PNG).
- **Git & GitHub Pages** — контроль версій та деплой проєкту.

## ✨ Функціонал

- Повний робочий інтерфейс головного екрана та футера.
- Динамічний пошук ресторанів при кліку на міста зі списку.
- Валідація та обробка форми передплати на розсилку.
- Повна адаптація типографіки під шрифт `Source Sans Pro` (700/900).
